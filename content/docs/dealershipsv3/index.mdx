# MT Dealerships
An all-in-one **FiveM dealership system** supporting public, player-owned, used, and job-locked dealerships.

**Features**
- Player-Owned Dealerships
- Public Dealerships
- Player-Owned & Public Used Dealerships
- Vehicle Financing with Customer Dashboard
- Job-Locked Dealerships
- Dynamic Vehicle Stock Management
- Dealership Re-Stocking Missions
- In-Game Dealership Creator
- Dealership Management Dashboard with Detailed Insights


**Dependicies**
- ox_lib
- ox_target
- oxmysql
- qbx_core, qb-core or es_extended
