---
title: Installation
---

There is not much you need to do for this script installation.
Just drag it to your resources folder and start in the server.cfg.

The script will install all SQL queries automatically, select your framework and dependicies also automatically.
If you use any other dependicies than the default ones in our script, gotta update them in the modules files.

Also, if you want to change some settings on the script, you have a few configuration options in the config folder files.
After all that, go in-game, do the command /dealershipscreator and start creating your dealerships locations and vehicles.

Enjoy :)
