# Explore our development exports

## Server exports

**Get buffs values**
This will return the active percentage of requested buff

```lua
---@param source number
---@param buffid string
---@return number
exports.mt_restaurants:getBuff(source, buffid)
```

**Get restaurants**
Gets all restaurant and food truck configurations

```lua
--- @return table[] restaurants List of all restaurant configuration objects
exports.mt_restaurants:getRestaurants()
```

**Get restaurant recipes**
Gets all recipes registered for a specific restaurant directly from memory cache

```lua
--- @param restaurantId string|number The ID of the restaurant.
--- @return table[] recipes Array of recipe objects for the specified restaurant.
exports.mt_restaurants:getRestaurantRecipes(restaurantId)
```

**Get offline shop items**
Gets all items and stock currently stored in the offline shop for a restaurant

```lua
--- @param restaurantId string|number The ID of the restaurant.
--- @return table[] items List of inventory items in the offline shop stash.
exports.mt_restaurants:getOfflineShopItems(restaurantId)
```

**Add offline shop stock**
Adds item stock to the offline shop stash for a restaurant

```lua
--- @param restaurantId string|number The ID of the restaurant.
--- @param itemName string Name of the item to add.
--- @param quantity number Amount of the item to add (must be > 0).
--- @param metadata? table Optional item metadata.
--- @return boolean success True if stock was added successfully, false otherwise.
exports.mt_restaurants:addOfflineShopStock(restaurantId, itemName, quantity, metadata)
```

**Remove offline shop stock**
Removes item stock from the offline shop for a restaurant. Checks if sufficient stock exists before removing

```lua
--- @param restaurantId string|number The ID of the restaurant.
--- @param itemName string Name of the item to remove.
--- @param quantity number Amount of the item to remove (must be > 0).
--- @return boolean success True if stock was removed, false if item/stock is missing or insufficient.
exports.mt_restaurants:removeOfflineShopStock(restaurantId, itemName, quantity)
```

## Server hooks

**Register server hook**
Registers a callback listener for lifecycle events (`OnItemPrepared`, `OnOrderCompleted`, `OnOrderStatusChanged`). Supports optional filtering

```lua
--- @param event string Event name ('OnItemPrepared', 'OnOrderCompleted', 'OnOrderStatusChanged').
--- @param callback function Function to execute when event triggers.
--- @param options? table Optional filters: { restaurantFilter = string|number|table, jobFilter = string|table, itemFilter = string|table }.
--- @return number hookId Unique ID of the registered hook (used to remove).
exports.mt_restaurants:registerHook(event, callback, options)
```

**Remove server hook**
Unregisters a previously registered server hook by its ID

```lua
--- @param hookId number The ID of the hook returned by registerHook.
--- @return boolean success True if the hook was found and removed, false otherwise.
exports.mt_restaurants:removeHook(hookId)
```

**Get restaurant orders history**
Gets historical completed orders from the database for a specific restaurant

```lua
--- @param restaurantId string|number The ID of the restaurant.
--- @param limit? number Optional max number of records to return (defaults to 100).
--- @return table[] orders List of order objects with decoded orderData, citizen IDs, and items.
exports.mt_restaurants:getRestaurantOrdersHistory(restaurantId, limit)
```

**Get restaurant statistics**
Gets aggregated revenue and order count statistics for a restaurant

```lua
--- @param restaurantId string|number The ID of the restaurant.
--- @return table stats Object containing dayRevenue, dayOrders, monthRevenue, monthOrders, totalRevenue, and totalOrders.
exports.mt_restaurants:getRestaurantStatistics(restaurantId)
```
