# MT Vehicle Keys
Complete and optimized vehicle keys script for FiveM

**Features**
- Locksmith to request new keys and change the vehicle's lock
- Vehicle keys by id for owned vehicle letting you change the lock id to no longer let players with the keys to access your vehicle
- Keys by item
- The engine stays on if you left the vehicle on even if you leave the vehicle
- Custom lock and unlock sound
- Animations when locking and unlocking and when toggling the vehicle engine
- Motorcycles don't lock and bicycles don't have key at all
- Custom lockpick minigame inspired in the game "OSU"
- The vehicle alarm goes off when you fail the lockpick
- Once the vehicle is unlocked and hotwired with the lockpick, you can lo longer turn it off or lock it unless you have the key

**Dependicies**
- ox_target
- ox_lib
- ox_inventory
